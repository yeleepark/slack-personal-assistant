# slack-personal-assistant

Slack에서 쓰는 개인 비서입니다. 매번 직접 들어가서 확인하던 일을 대신 확인해서 슬랙으로 알려 주고, 물어보면 바로 답합니다.

## 기능

**제휴 수익 알림** (`projects/earnings-alert`)

쿠팡 파트너스, 마이리얼트립, 네이버 브랜드커넥트의 어제 수익을 한 번에 모아서 보여 줍니다. 소스별 금액과 이번 달 누적, 전일 대비 증감까지 함께 나옵니다.

```
💰 2026-11-14 제휴 수익
• 쿠팡 파트너스: 12,300원 · 이번 달 누적 98,000원 · 전일 대비 ▲4,100원
• 마이리얼트립: 0원 · 이번 달 누적 0원 · 전일 대비 변동 없음
• 브랜드커넥트: 410원 · 이번 달 누적 1,490원 · 전일 대비 ▲310원
합계: 12,710원
```
> 위 숫자는 예시입니다.

## 사용법

| 방법 | 어떻게 |
| --- | --- |
| 자동 알림 | 설정해 두면 매일 정해진 시각(기본 16:30)에 채널로 알림이 옵니다 |
| 슬래시 커맨드 | 아무 채널에서 `/블로그수익` 을 입력하면 잠시 뒤 결과가 올라옵니다 |
| 앱 멘션 | 채널에서 앱을 멘션하면 스레드로 답합니다 |

## 설치

Mac 한 대에서 상시 실행합니다. 슬랙 앱 만들기부터 설치까지는 [earnings-alert README](projects/earnings-alert#설치)를 따라 하세요.
