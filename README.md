# slack-personal-assistant

**Slack에서 쓰는 개인 비서.** 채널에서 슬래시 커맨드를 치거나 앱을 멘션하면 대신 확인해서 답해 주고, 정해진 시각에는 먼저 알려 줍니다.

```
나      /블로그수익
비서    ⏳ 조회 중이에요 (1분쯤 걸려요)
비서    💰 2026-11-14 제휴 수익
        • 쿠팡 파트너스: 12,300원 (클릭 41 · 구매 3건) · 이번 달 누적 98,000원 · 전일 대비 ▲4,100원
        • 마이리얼트립: 0원 (예약 0건) · 이번 달 누적 0원 · 전일 대비 변동 없음
        • 브랜드커넥트: 410원 (클릭 8 · 판매 1개) · 이번 달 누적 1,490원 · 전일 대비 ▲310원
        합계: 12,710원 (전일 8,310원 → ▲4,400원)
```
> 위 숫자는 예시입니다.

## Slack에서 쓰는 방법

| 방법 | 설명 |
| --- | --- |
| 자동 알림 | 정해진 시각(기본 매일 16:30)에 채널로 먼저 알려 줍니다 |
| 슬래시 커맨드 | 아무 채널에서 `/블로그수익` — 앱을 초대하지 않은 채널에서도 동작 |
| 앱 멘션 | `@앱이름` 으로 부르면 스레드로 답합니다 |

공개 서버나 URL 없이 Slack **Socket Mode**(웹소켓)로 동작하므로, 집에 있는 Mac 한 대에서 상시 실행하면 됩니다.

## 규칙

- 프로젝트마다 독립 폴더이고, 각자 README·`.env.example`·설치 스크립트를 가집니다.
- 비밀값(Slack 토큰, API 키, 웹훅 URL)은 `.env`에만 두고 커밋하지 않습니다. 필요한 항목은 `.env.example`에 빈 값으로 적습니다.
- 로그인 세션·수익 기록 같은 개인 데이터(`.chrome-profile/`, `history.json`, `*.log`)도 커밋하지 않습니다. 루트 `.gitignore`가 막아 둡니다.
